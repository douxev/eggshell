# EggshellLogo

The Eggshell brand mark — a warm egg on cream. Brand colours are fixed (`--brand-*`), so the logo looks identical in every palette. Use `icon` for the launcher lockup, `mark` for the bare egg.

```tsx
<EggshellLogo size={64} />
<EggshellLogo variant="mark" size={16} />
```
