## 🇫🇷 Version française

Mise à jour **0.0.9** — toutes les nouveautés récentes, désormais aussi listées
dans le panneau « Quoi de neuf » de l'app.

### Quoi de neuf

- **Menstruations / cycle** : nouvel onglet (opt-in) pour noter règles, spotting
  et symptômes (abondance, douleur, crampes). Aucune prédiction de cycle.
- **Jauges personnalisables** : renomme, réordonne et ajoute tes propres curseurs
  (avec emojis) dans le Journal et les Menstruations.
- **Corrélations** : ton humeur en regard de tes prises, changements de traitement
  et jours de règles (fenêtres 30 / 90 / 180 jours). Descriptif, sans relation de
  cause à effet.
- **Édition de traitement** : modifie un traitement ; les changements de dose/voie
  sont historisés pour les corrélations.
- **Couleur des traitements** : un sélecteur de couleur pour repérer chaque
  traitement d'un coup d'œil.
- **Leurre persistant** : l'appli de notes leurre garde tes notes de couverture
  entre les sessions, isolée du vrai coffre, effacée au wipe.
- **Rappels sur mesure** : mode d'affichage (générique / nom / alias) pour la
  discrétion sur l'écran verrouillé, priorité par rappel, et rappels séparés
  labo / photo / voix.
- **Ton plus accueillant** : « traitement », « Médics », tutoiement partout.

### Sécurité

Toutes tes données restent chiffrées en local (AES-GCM, Argon2id, SQLCipher).
Aucune connexion internet. Le mode de sécurité ne décide que de la façon dont tu
ouvres l'app.

### Installer

Télécharge `eggshell-0.0.9.apk` ci-dessous et installe-le (autorise « sources
inconnues » si demandé). Mise à jour par-dessus une version précédente : tes
données sont conservées.

## 🇬🇧 English version

Update **0.0.9** — all the recent additions, now also listed in the app's
"What's new" panel.

### What's new

- **Periods / cycle**: new opt-in tab to log bleeding, spotting and symptoms
  (flow, pain, cramps). No cycle prediction.
- **Customizable gauges**: rename, reorder and add your own sliders (with emojis)
  in the Journal and Periods.
- **Correlations**: your mood next to your doses, treatment changes and bleeding
  days (30 / 90 / 180-day windows). Descriptive only.
- **Edit a treatment**: dose/route changes are kept for the correlation timeline.
- **Treatment color**: a color picker to spot each treatment at a glance.
- **Persistent decoy**: the decoy notes app keeps your cover notes across
  sessions, isolated from the real vault, wiped on full wipe.
- **Tailored reminders**: content mode (generic / name / alias) for lock-screen
  discretion, per-reminder priority, separate lab / photo / voice reminders.
- **Warmer wording** throughout.

### Security

All your data stays encrypted on-device (AES-GCM, Argon2id, SQLCipher). No
internet connection. The chosen security mode only changes how you open the app.

### Install

Download `eggshell-0.0.9.apk` below and install it (allow "unknown sources" if
prompted). Updating over a previous version keeps your data.
